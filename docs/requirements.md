# オフィス用音楽生成アプリ - 要件定義

## プロジェクト概要
オフィスが静かすぎる環境を改善するため、時間帯に応じて自動的に音楽を生成・再生するアプリケーション

## 基本要件

### 1. プラットフォーム
- **第一段階**: Webアプリケーション（プロトタイプ）
- **最終目標**: iOSアプリ

### 2. 音楽生成方式
- **採用方式**: アルゴリズム音楽生成（Web Audio API / Tone.js）
- **理由**:
  - 完全無料で実装可能
  - オフラインで動作
  - リアルタイム生成
- **代替案**: AI音楽生成API（Mubert等）は有料のため保留

### 3. 音楽スタイル
ユーザーが選択可能な3つのスタイル：
- **アンビエント**: 環境音楽、落ち着いた雰囲気
- **ローファイ**: チルでリラックスした雰囲気
- **ジャズ**: 軽快なジャズ風サウンド

### 4. 時間帯の自動検出と音楽の変化

#### 時間帯区分
| 時間帯 | 時間範囲 | 絵文字 | 音楽の雰囲気 |
|--------|----------|--------|--------------|
| 朝（出勤時） | 6:00 - 8:59 | 🌅 | energetic（活気のある） |
| 午前 | 9:00 - 11:59 | ☀️ | focused（集中的） |
| 昼休み | 12:00 - 12:59 | 🍱 | relaxed（リラックス） |
| 午後 | 13:00 - 16:59 | 💼 | calm（落ち着いた） |
| 夕方 | 17:00 - 19:59 | 🌆 | mellow（穏やかな） |
| 夜 | 20:00 - 5:59 | 🌙 | peaceful（平和な） |

#### 音楽パラメータの変化
各時間帯と雰囲気に応じて以下が自動調整される：
- **音階（スケール）**: 使用する音の組み合わせ
- **テンポ（BPM）**: 曲の速さ
- **音色**: シンセサイザーの種類

## 機能要件

### 必須機能
1. **再生コントロール**
   - 再生開始ボタン
   - 停止ボタン
   - 曲を変更ボタン（同じ設定で再生成）

2. **スタイル選択**
   - アンビエント、ローファイ、ジャズの切り替え
   - 再生中でもリアルタイムで変更可能

3. **情報表示**
   - 現在時刻の表示
   - 現在の時間帯の表示
   - 再生状態（再生中/停止中）
   - 音楽設定情報（スタイル、テンポ、雰囲気）

4. **自動更新**
   - 1時間ごとに時間帯を再検出し、音楽を自動更新
   - 時計の1秒ごとの更新

### オプション機能
- ビジュアライザー（音楽の視覚化）
- 音量調整機能（将来的に追加可能）

## 技術スタック

### Webアプリ版
- **フロントエンド**: HTML5, CSS3, JavaScript
- **音楽生成**: Web Audio API
- **オプション**: Tone.js（より高度な音楽制御）

### iOS版（将来）
- **言語**: Swift
- **音楽生成**: AVFoundation + AudioKit
- **代替案**: AI音楽生成API統合（予算次第）

## 非機能要件

### パフォーマンス
- ブラウザでスムーズに動作
- CPU負荷は最小限に
- メモリリークなし

### ユーザビリティ
- シンプルで直感的なUI
- ワンクリックで再生開始
- モバイル対応（レスポンシブデザイン）

### コスト
- **完全無料**: 外部APIやサービスへの依存なし
- **オフライン動作**: インターネット接続不要

## デザイン要件

### カラースキーム
- メインカラー: パープル系グラデーション（#667eea → #764ba2）
- アクセントカラー: 機能ごとに異なる（再生、停止、変更）
- 背景: 半透明の白（rgba(255, 255, 255, 0.95)）

### レイアウト
- カード型UI
- 中央配置
- 最大幅: 600px
- レスポンシブ対応

## 制約事項

### 技術的制約
- ブラウザのWeb Audio API対応が必須
- 最初のクリックまで音声再生不可（ブラウザのセキュリティ仕様）
- 本格的なAI生成音楽ではなく、アルゴリズム生成

### ビジネス的制約
- 予算: ゼロ
- 開発期間: 即座にプロトタイプ作成
- 外部サービス依存: なし
